# auth.md

Classroom is a public, read-only cybersecurity learning site. Agents may read public pages, `llms.txt`, the search index, and well-known discovery metadata without creating an account or requesting credentials.

## public access

No token is required for public content. Use the `public.read` scope label when a client needs to describe its intended access.

## registration

Automated self-service agent registration is not required for this public content site. For coordination or abuse reports, contact the site owner through the public GitHub profile at `https://github.com/anir0y`.

## authorization

There is no interactive authorization flow for the public site.

## tokens

The public site does not issue bearer tokens.
